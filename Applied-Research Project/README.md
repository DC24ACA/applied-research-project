# Applied Research Project

## Project Overview

This repository contains the planning, literature review, methodology, implementation, evaluation and documentation for my MSc Applied Research Project in Computer Science (Cyber Security).

The repository is maintained throughout the project to document the evolution of the research, including project planning, literature review, methodological decisions, implementation, experimental results and dissertation development.


## Proposed Project Title

**Assessing the Feasibility of Autonomous Large Language Models for Endpoint Security Incident Investigation Using Wazuh and Sysmon Evidence**

**Note:** This is a working title and may be refined following the literature review and discussions with my project supervisor.


## Project Aim

The aim of this research is to investigate the extent to which large language models (LLMs) can autonomously interpret security alerts and endpoint telemetry to produce accurate, complete and evidence-supported incident investigations within a simulated Security Operations Centre (SOC).

The project will utilise Wazuh and Sysmon to generate endpoint security evidence from controlled cyber attack scenarios. Multiple large language models will be evaluated using identical evidence and compared against independently established ground truth to assess their suitability for autonomous incident investigation.

## Research Workflow

The project follows the following workflow:

1. Conduct a comprehensive literature review.
2. Identify the research gap and refine the research question.
3. Design the experimental methodology.
4. Build the experimental SOC environment.
5. Generate controlled attack scenarios.
6. Collect Wazuh alerts and Sysmon logs.
7. Evaluate multiple LLMs using identical evidence.
8. Compare outputs against independently established ground truth.
9. Analyse the results using quantitative and qualitative evaluation metrics.
10. Produce the final dissertation and presentation.
