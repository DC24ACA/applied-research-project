# Meeting Notes

## Purpose

This folder contains records of meetings held throughout the Applied Research Project.

Supervisor Contact Point (SCP) log forms are stored as the main record of each meeting. These documents capture completed work since last contact point, feedback, agreed actions and project progress.

Additional notes or supporting documentation may also be included where appropriate.

---

## Contents

- Supervisor Contact Point (SCP) log forms
- Additional meeting notes (if required)
- Supporting documents relating to supervisor meetings

---

## Status

Active - to be updated monthly after each SCP
