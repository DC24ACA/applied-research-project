# Alert2Vec: Eliminating Alert Fatigue by Embedding Security Alerts Through Subgraph Learning

## Bibliographic Information

Citation: Wu, S., Sun, X., Dong, E., Wang, Z., Zhao, C. and Yang, J. (2026). Alert2Vec: Eliminating Alert Fatigue by Embedding Security Alerts Through Subgraph Learning. IEEE Transactions on Dependable and Secure Computing, 23(1), pp. 655–669. DOI: 10.1109/TDSC.2025.3609834.

Supporting Literature

Status: Read 

## Research Aim

* Reduce alert fatigue by automatically prioritising security alerts.
* Correlate alerts from both host-level and network-level security devices.
* Classify alerts according to their threat level.

## Methodology

* Converted alerts into an Alert Intelligence Graph using subject, action and object relationships.
* Used subgraph learning to generate numerical representations of correlated alerts.
* Tested semi-automatic and fully automatic threat classification on three real-world datasets.

## Key Findings

* Achieved 94.7% accuracy on the network dataset and 95.6% on the host dataset.
* Achieved 99.1% accuracy on the public NIDS alert dataset.
* Correlating multiple alerts improved threat prioritisation compared with analysing alerts individually. 

## Strengths

* Uses large real-world security alert datasets.
* Works with both host and network security alerts.
* Demonstrates the importance of correlating evidence across multiple alerts.

## Limitations Relevant to My Scope

* Focuses on alert classification rather than full incident investigation.
* Uses machine learning and graph techniques rather than LLMs.
* Performance depends heavily on complete historical alert data.

## Relevance to My Project

* Shows why individual alerts should not always be analysed in isolation.
* Supports correlating multiple pieces of evidence when reconstructing an incident.
* Provides background on automation reducing analyst workload and alert fatigue.
