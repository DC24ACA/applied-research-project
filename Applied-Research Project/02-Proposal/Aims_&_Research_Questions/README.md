# Project Title
### Assessing the Feasibility of Autonomous Large Language Models for Security Incident Investigation Using Wazuh and Sysmon Evidence
## Aim
The aim of this project is to assess whether large language models can autonomously reconstruct and investigate security incidents using Wazuh alerts and Sysmon endpoint data, producing accurate, complete and evidence-supported investigation reports.
## Primary Research Question
To what extent can Large Language Models autonomously investigate security incidents using Wazuh and Sysmon evidence?
## Sub-questions
1. How accurately do selected LLMs identify and reconstruct known malicious activity when compared with established ground truth?
2. How completely do selected LLMs identify the actions and sequence contained within the established ground truth?
3.	What proportion of conclusions made by selected LLMs are supported by the supplied Wazuh and Sysmon evidence?
