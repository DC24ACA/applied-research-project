# Ethics

This project does not involve human participants or third-party participation. Experimental work will use a controlled, isolated Windows environment, publicly available security data, Wazuh and Sysmon evidence and LLM-generated outputs.

The project supervisor advised that formal ethics approval was unlikely to be required. University policy along with module guidance were reviewed and no requirement for formal ethics approval was identified for the proposed methodology.

Formal ethics approval is not required for the current project scope.
