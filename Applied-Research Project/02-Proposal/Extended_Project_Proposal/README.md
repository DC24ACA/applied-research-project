# Current title
Assessing the Feasibility of Autonomous Large Language Models for Security Incident Investigation Using Wazuh and Sysmon Evidence

# Aim
Assess whether LLMs can autonomously reconstruct and investigate security incidents using Wazuh and Sysmon evidence.

# Main change from IPI
The project no longer compares manual and AI-assisted investigation. Investigations generated by LLMs will instead be evaluated against independently established ground truth to avoid analyst experience affecting the comparison.

# Methodology
Windows APT attack scenarios 
Wazuh/Sysmon evidence 
Independent ground truth 
Equivalent evidence and instructions given to selected LLMs 
Reports evaluated for accuracy, completeness and evidence support.
