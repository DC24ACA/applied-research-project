# Experimental Setup

## Virtual Lab Environment

The experimental environment was created using VMware Workstation Pro on a Windows 11 host machine. Two virtual machines were configured to provide an isolated environment for generating and monitoring security activity. A Windows Enterprise VM was used as the monitored endpoint, while an Ubuntu 22.04.5 LTS VM was used to host Wazuh.

## Windows Endpoint

The Windows VM acts as the target endpoint for the controlled attack scenarios. Sysmon was installed to provide detailed logging of endpoint activity, including process creation, network activity and other security-relevant events. A Wazuh agent was also configured on the Windows VM so that security events could be collected and analysed through Wazuh.

## Wazuh Environment

Wazuh was installed on the Ubuntu VM using an all-in-one configuration. The Ubuntu VM was allocated 4 virtual CPUs and 8 GB of RAM. Wazuh is used to collect and process security information generated by the Windows endpoint and provides the alerts and supporting evidence used during the investigation.

## Atomic Red Team

Atomic Red Team was installed on the Windows VM to generate controlled and repeatable attack activity. Selected Atomic Red Team tests will be executed individually so that the actions performed are known in advance and can be compared with the resulting Sysmon events and Wazuh alerts. This will provide the simpler attack scenarios used within the project.

## Windows APT Dataset

The Windows APT dataset will be used to provide more complex, multi-stage attack scenarios. Relevant sections of the dataset will be selected using the available scenario information and manifest files. The associated security telemetry will then be extracted and prepared for analysis by the LLMs.

## Evidence Collection

Evidence used during each investigation will consist primarily of Sysmon endpoint telemetry and Wazuh alerts. Relevant evidence will be collected for the time period associated with each attack scenario and prepared before being provided to the LLMs. Only information required to support the investigation will be retained, helping to keep the evidence consistent and manageable across each model.
